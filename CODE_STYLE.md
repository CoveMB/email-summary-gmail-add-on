# Code Style Summary

- Use strict TypeScript.
- Prefer functional, pure helpers.
- Keep Apps Script side effects isolated.
- Use fully spelled-out variable names.
- Keep functions small and purpose-specific.
- Do not duplicate existing logic.
- Search before creating new helpers.
- Document exported and security-sensitive functions.
- Never log Gmail bodies, prompts, AI responses, keys, or tokens.
- Keep Marketplace readiness in mind with every OAuth/data-access change.
- Run `npm run check` before finishing.
